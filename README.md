# 扫雷 Minesweeper

一个纯前端的单文件扫雷游戏：只有 `扫雷.html` 一个文件，双击用浏览器打开即可开玩，不需要安装依赖、不需要联网、不需要构建。

## 玩法与操作

| 操作 | 说明 |
| --- | --- |
| 左键点击 | 翻开格子 |
| 右键点击 | 插旗 / 取消旗 |
| 长按约 0.4 秒 | 触屏插旗（带轻微震动反馈） |
| 双击数字 / 中键 | 快速展开：当周围旗数等于该数字时，一次性翻开周围格子 |
| `R` | 重新开始本局 |
| `F` | 切换插旗模式（勾选后单击即插旗，适合触屏） |
| 点击笑脸 | 🙊 正常 / 😎 通关 / 😵 踩雷，点它重开 |

## 功能

- **三档经典难度**：初级 9×9 / 10 雷，中级 16×16 / 40 雷，高级 16×30 / 99 雷
- **自定义难度**：行 5–40、列 5–60，雷数自动限制为不超过格子总数的 60%
- **首点必安全**：第一次点开的位置及其周围一圈都不会布雷，开局不会被秒
- **空白成片展开**：翻开空白格时自动展开相连的空白区域（洪水填充）
- **剩余雷数计数**与**计时器**
- **踩雷反馈**：显示全部雷位，插错的旗用 ❌ 标出
- **通关反馈**：自动补旗、显示用时，并按难度记录最佳成绩（浏览器 localStorage）

## 兼容性

适用于任何现代浏览器（Chrome / Edge / Firefox / Safari），鼠标、触屏、触控板均可操作；棋盘会按窗口宽度自动调整格子大小，大棋盘可横向滚动，手机上也能玩。
